# 외출 지도 배경 제작 기준

현재 구현한 지도는 기존 픽셀 아이콘으로 구성한 **장소 배치·이동 시안**입니다. 최종 AI 생성 배경으로 표시하지 않습니다. 이번 환경에서는 built-in image_gen 도구가 제공되지 않아 새 생성 이미지는 제작하지 않았습니다.

## 고정할 구도

- 지도는 방과 별개의 외출 장소 선택 화면. 화면 내부의 가로 영역을 사용합니다.
- 내 방: 왼쪽 아래 (x 23%, y 67%). 광장: 가운데 위 (51%, 32%). 상점: 오른쪽 아래 (79%, 66%).
- 세 장소를 크림색 산책길로 연결. 주변은 부드러운 하늘색 물과 낮은 초록 잔디.
- 글자·선택 표시·목적지 버튼은 코드로 겹칩니다. 생성 이미지에는 글자를 넣지 않습니다.
- 고양이·다마고치 본체·버튼·메뉴·다른 장소는 배경에 그리지 않습니다.
- 이후 실제 이미지가 정해지면 mapTerrain 부분과 위치 좌표를 함께 조정합니다.

## 이미지 요청 프롬프트

그못섬 게임의 외출 장소 선택용 작은 섬 지도 배경. 한국어 사용자용 아늑한 픽셀아트 생활 게임이며, 2D RPG처럼 위에서 내려다보아 건물 지붕과 앞면이 함께 보이는 시점. 가로 2:1 구도. 파스텔 하늘색 물에 둘러싸인 작은 잔디 섬, 크림색 산책길, 절제된 작은 꽃과 나무. 왼쪽 아래 23%,67% 지점에 하늘색 지붕의 작은 집, 가운데 위 51%,32% 지점에 열린 작은 광장, 오른쪽 아래 79%,66% 지점에 작은 상점. 세 장소를 길로 연결하고 서로 충분히 떨어뜨려 클릭하기 쉽게 배치. 둥글고 귀여운 형태, 일정한 픽셀 크기, 읽기 쉬운 단순한 실루엣. 기존 블루·화이트 다마고치 기기와 잘 어울리는 부드러운 색. 글자, 간판의 문자, UI, 테두리, 버튼, 캐릭터, 워터마크 없음. 병원·놀이동산 등 추가 시설 없음.
