# 그못섬 마이룸 카메라 및 가구 배치 기준 — 초안

> **에셋 색상·윤곽의 최신 확정 기준:** [픽셀 에셋 제작 기준서](pixel-asset-style-guide.md) · 개별 에셋 **기본 2색, 최대 3색(외곽선 포함; 투명색 제외)**. 이전 색상 수·그라데이션 제안보다 우선합니다.

- 목표: 사용자가 선택한 정면에 가까운 미들앵글 2.5D, 가로 4:3 콘솔 화면.
- 공통 논리 좌표: 170 × 128. 테마·화면 크기가 달라져도 게임 좌표는 유지.
- 임시 바닥 경계: y=72/128 (바닥 43.75%). 가구 렌더링과 드래그에서 동일한 경계 사용.
- 일반 가구: 이미지의 아래쪽을 바닥 접점(발점)으로 사용. 발점이 바닥 영역에서 벗어나지 않음.
- 벽 부착형: cream_f2, pink_f2 (커튼창). 벽 영역에서만 이동.
- 고양이: 발 위치 y=72~124만 허용. X축 범위는 기존 170월드와 해당 캐릭터 크기를 따름.
- 깊이 정렬: 기존 footY 정렬과 투명 픽셀 기반 전면 선택을 유지.
- 가구 원본은 리사이즈하지 않고, 가구 자체의 도트 스케일 및 방향을 맞춰 제작.
- 기본 마이룸 배경에 고정되는 것은 건축 구조(벽, 창문, 바닥)뿐. 조명, 꽃병, 랜턴, 선반, 스크린, 가구와 캐릭터는 별도 에셋.
- 이번 변경은 **좌표 규칙 기반 작업**이며, 승인된 핑크 다락방 빈 배경 및 최종 가구 아트 교체 작업은 포함하지 않음.

## 실제 화면 검증 필요
1. 게임기 내부 화면 4:3에서 고양이 표정과 가구 윤곽이 충분히 보이는지
2. 10개 이상의 가구 이동 및 저장 후 새로고침 복원
3. 가구의 발점 정렬, 벽 장식 제한, 모바일 터치 편집
4. 사용자가 승인한 분리형 핑크 배경 및 가구 에셋 적용 후 미들앵글 구도 일치 확인

이 문서는 앱에서 읽는 `ROOM_CAMERA_STANDARD` 값을 기준으로 갱신합니다.
