# 그못섬 픽셀 에셋 제작 기준서

> 최종 정정: **2026-11-12**. 최신 사용자 설명이 이전의 '에셋 전체 2~3색' 해석보다 우선합니다.

## 1. 색상 규칙: 소재·부품별 제한

**색상 제한의 단위는 에셋 전체가 아니라, 가구 안의 개별 소재 또는 기능 부품입니다.**

- **소재/부품 하나당 기본색 1개 + 명암색 1개 = 기본 2색.** 정말 필요한 경우에만 해당 소재/부품의 3번째 색(하이라이트 또는 추가 명암)을 허용합니다.
- **전체 가구에 사용하는 색상이 3색을 초과해도 됩니다.** 예를 들어 텐트의 천, 리본, 쿠션, 목재 지지대는 각각 독립된 2색(필요시 최대 3색) 팔레트를 가질 수 있습니다.
- **짙은 갈색 계열의 공통 외곽선 색상은 위 소재 팔레트 예산에서 별도로 관리**합니다. 외곽선의 색을 여러 색으로 무분별하게 늘리지 않습니다.
- 소재/부품의 경계는 구조와 용도가 실제로 다른 부분이어야 합니다. 같은 천의 명암을 늘리기 위해 인위적으로 여러 '부품'으로 쪼개서 색상 제한을 회피하지 않습니다.
- 투명 픽셀은 색상이 아닙니다. PNG의 알파는 가능하면 0 또는 255로 처리하고 흐릿한 반투명 가장자리는 쓰지 않습니다.

### 예시: 텐트
| 구분 | 허용 표현 |
|---|---|
| 텐트 외부 천 | 크림 기본색 + 크림 그림자색 (2색), 필요시 1색 추가 |
| 리본 | 핑크 기본색 + 핑크 그림자색 (2색) |
| 내부 쿠션 | 쿠션 기본색 + 쿠션 그림자색 (2색) |
| 목재 기둥 | 목재 기본색 + 목재 그림자색 (2색) |
| 윤곽선 | 공통 짙은 갈색 1색, 위 색수 계산과 별도 |

### 예시: 냉장고
냉장고 몸체(기본 크림+그림자 크림), 손잡이(기본 갈색+그림자 갈색), 자석·메모·바구니(각자 소재별 색)로 나눕니다. **냉장고 전체를 2~3색으로 만들라는 규칙이 아닙니다.**

## 2. 픽셀 스타일
- 표현 기준: **2026-11-12 사용자가 첨부한 픽셀 주방 레퍼런스 `IMG_6125.jpeg`**. 진한 갈색 계열의 깨끗하고 연속된 윤곽선, 큰 픽셀의 정돈된 형태, 적은 단계의 단단한 명암.
- 제작 논리 그리드 기준 외곽선은 보통 **1픽셀**이며, 중요 부품 앞면·다리·손잡이가 잘리지 않아야 합니다.
- 픽셀아트 경계는 선명하게, **그라데이션·블러·안티앨리어싱 금지**. 촘촘한 무의미한 노이즈나 흐린 반투명 점도 금지.
- 가구 시점을 통일하고 가로·세로 비율을 **비등방적으로 늘리지 않습니다**. 목표 화면에 맞춰 실제 픽셀 그리드에서 새로 그린 다음 최근접 이웃/정수배 확대를 이용합니다.
- 완성본은 **가구별 독립 투명 PNG**, 적절한 투명 여백, 기준 크기, 접지점(anchor), 부착/배치 표면(벽/바닥/상판)을 포함합니다.

## 3. 작업에서 보존할 것
- 게임 화면 **4:3**, 정면을 중심으로 한 미들앵글 2.5D; 게임 논리좌표는 **170×128**. 최종 각도는 실제 배치 검증을 거쳐야 합니다.
- 사용자가 선택한 **핑크 겨울 다락방의 빈 배경**, 원본 완성 합성 사진을 기본 가구 배치/크기 기준으로 사용합니다.
- **기존 8방향 고양이는 보존**합니다: `src/assets/selected-room-20261112/cat/` 아래 8개 이미지 및 `src/selected-cat.js` 이동방향 코드. 새 고양이 생성·교체 금지.
- 배경에 고정되는 것은 벽·바닥·창문 같은 건축 구조입니다. 조명줄·스탠드·선반·화분·러그·소품 등은 별도 배치 에셋입니다.

## 4. 제작/검증 순서
1. 사진에서 형태·시점·부위·소재를 분석하고, 각 소재의 **2색(필요시 최대 3색)** + 공통 윤곽 팔레트를 정의합니다.
2. 단독 가구를 **실제 게임 크기에서** 제작합니다. 전체 다색 시트를 생성해 잘라서 축소하는 방식은 피합니다.
3. **소재별로 사용한 불투명 RGB 색상 수가 3개 이하인지** 각 영역 마스크 또는 레이어와 팔레트 매핑을 통해 검증합니다. **전체 PNG의 RGB 고유색 개수를 3으로 제한하거나, 전체 색수만으로 불합격 판정하지 않습니다.**
4. 알파 경계, 명확한 1픽셀 윤곽, 가구 끝단 잘림, 왜곡/리샘플링, 콘솔 실측 가독성을 검수합니다.
5. 원본 합성 이미지의 상대 가구 크기/위치를 기준으로 빈방+기존 고양이와 합성합니다. 고양이를 생성된 대체 이미지로 변경하지 않습니다.
6. 실게임 적용 후 드래그, 깊이, 저장/복원, 8방향 이동, 모바일 화면 테스트를 수행하고 GitHub 커밋 및 실제 배포를 확인합니다.
7. **생성된 시안/검수용 PNG/운영 게임에 적용된 PNG를 구분해서 기록**합니다.

## 5. 이전 문서의 잘못된 판정 정정
- 과거의 **'에셋 전체 총 2~3색, 외곽선 포함' 규정은 오류였으며 폐기**되었습니다.
- 이전 6개 시제품(텐트 8색, 티테이블 8색, 원형 러그 7색, 꽃무늬 러그 6색, 바닥 침구 6색, 쿠션 5색)의 **전체 RGB 고유색 수 측정 자체는 이전 검사 결과**입니다. 그러나 해당 수치만으로 **현재 소재별 2~3색 규정 불합격을 판단할 수는 없습니다**. 부위별 실제 팔레트, 흐림/잘림/비율을 **새 규정으로 재검수**해야 합니다.
- `src/art-style.js`에는 smoothing 코드가 남아 있으며 문서 수정만으로 게임 렌더러가 합격하는 것은 아닙니다.
- 시점·위치 세부값은 [카메라/배치 기준서](room-camera-standard.md), 후속 협업 기준은 [프로젝트 메모리](../MEMORY.md)를 따릅니다.
