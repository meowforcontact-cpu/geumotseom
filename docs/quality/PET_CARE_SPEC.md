## 1. 상태 및 친밀도 (PET-01)
포만감·기분·청결도·친밀도 네 상태를 0~100 범위에서 펫별로 저장한다. 마이룸에서 현재 대표 펫의 네 상태를 상시 표시한다. 친밀도는 장기 유대감 지표이며 시간 경과로 감소하지 않는다. 대표 펫 변경·재접속 시 각 펫의 상태/친밀도를 유지한다. 미접속으로 펫이 사망·소멸하거나 소유권을 잃지 않는다.

| 친밀도 | 단계 | 반응 |
| --- | --- | --- |
| 0~24 | 첫 만남 | 기본 돌보기 반응 |
| 25~49 | 친해지는 중 | 쓰다듬기 시 행복/부끄러움 |
| 50~74 | 친한 친구 | 접속 때 가까이 다가옴 |
| 75~99 | 아주 친한 친구 | 먼저 다가옴, 하트 효과 |
| 100 | 소중한 가족 | 최대 친밀도 전용 애정 표현 해금 |

친밀도는 냐냐냥·XP와 독립적이다. 일반 돌보기로 냐냐냥·XP를 직접 지급하지 않는다.

## 2. 표정 및 감정 표현
| 표정 | 발동 조건 |
| --- | --- |
| 기본 | 특별 행동 없음 |
| 행복 | 먹이·놀이 완료 |
| 졸림(콧방울) | 잠자기·휴식 |
| 슬픔(눈물) | 포만감 부족 |
| 놀람 | 갑작스러운 상호작용 |
| 사랑 | 친밀도에 따른 애정 표현 |
| 어질어질 | 특정 놀이 연출 |
| 부끄러움 | 쓰다듬기 |
| 삐짐 | 기분 또는 청결도 부족 |

화남 표정은 별도 제작하지 않고 기본 표정으로 대체한다. 부족 상태의 세부 발동 임계값은 별도 밸런스 검토 대상이다.

## 3. 행동 스프라이트
| 행동 | 권장 프레임 수 | 재생 |
| --- | ---: | --- |
| 대기 | 2 | 반복 |
| 걷기 | 방향별 4 | 반복 |
| 앉기 | 2 | 유지 |
| 눕기 | 2 | 유지 |
| 잠자기 | 3 | 반복 |
| 먹기 | 4 | 1회 |
| 놀기 | 4 | 1회 |
| 쓰다듬기 반응 | 3 | 1회 |

신규 스프라이트는 32×32 논리 픽셀, 정면·3/4·측면·후면 제작 참조 방향, 통일된 발점, 투명 PNG, 기존 눈·얼굴·외곽선 유지, 안티앨리어싱·블러·그라데이션 금지. 청소 및 친밀도 상승은 기존 행동 위의 반짝임·하트 효과를 우선 재사용한다. 세부 픽셀 규격은 [아트 기준서](../pixel-asset-style-guide.md) 및 [검수 가이드](ASSET_CHECK.md)를 따른다.

기존 승인된 8방향 고양이 원본 및 방향 전환 로직은 보호한다. 위 네 참조 방향은 8방향 원본을 줄이거나 교체하는 승인이 아니다. 신규 프레임과 기존 방향 간 매핑은 구현 전에 검증한다. 카메라·좌표·기존 가구 에셋은 이 승인으로 변경하지 않는다.

## 4. 행동 전환
대기 상태에서 사용자 상호작용이 있으면 유효한 먹기/놀이/쓰다듬기/청소 행동을 수행하고 상태를 갱신한다. 상호작용이 없으면 상태에 맞는 표정 또는 걷기·앉기·수면 등 자율 행동을 표시한다. 다른 입력으로 실행 중인 행동을 무조건 덮어쓰지 않고, 행동 종료 후 현재 상태에 맞는 표정으로 복귀한다.

## 5. 초기 상태 변화량
| 행동 | 포만감 | 기분 | 청결도 | 친밀도 (당일 첫 유효 수행) |
| --- | ---: | ---: | ---: | ---: |
| 먹이 주기 | +20 | +5 | 0 | +2 |
| 놀아주기 | -5 | +15 | 0 | +1 |
| 쓰다듬기 | 0 | +5 | 0 | +1 |
| 청소 | 0 | 0 | +25 | +1 |
| 잠자기 | 0 | 0 | 0 | 0 |

| 상태 | 시간당 감소 | 연속 미접속 1회 최대 감소 |
| --- | ---: | ---: |
| 포만감 | 3 | 36 |
| 기분 | 2 | 24 |
| 청결도 | 2 | 24 |
| 친밀도 | 0 | 0 |

미접속 감소량은 최대 12시간분만 반영한다. 예: 모두 100에서 시작하여 7일 미접속 시 포만감 64, 기분 76, 청결도 76, 친밀도 100. 상태는 0~100 범위를 벗어나지 않는다. 재접속·새로고침으로 동일 미접속 구간을 중복 계산하지 않는다.

## 6. 반복 돌보기 제한
| 행동 | 재사용 대기시간 |
| --- | ---: |
| 먹이 | 10초 |
| 놀이 | 5초 |
| 쓰다듬기 | 3초 |
| 청소 | 10초 |

- 친밀도는 각 펫의 각 행동별 당일 첫 유효 수행만 지급하며 일일 합계 최대 +5. KST 자정에 획득 제한을 갱신한다.
- 이미 최대 상태를 무의미하게 반복하는 행동은 친밀도 추가 인정하지 않는다. 쓰다듬기의 첫 유효 상호작용은 별도 인정한다.
- 친밀도 획득 한도에 도달해도 일반 돌보기는 가능하다.
- 동시 요청 및 반복 클릭으로 상태/친밀도가 중복 갱신되지 않아야 한다. 재접속·대표 펫 교체로 제한이 초기화되지 않아야 한다.
- 친밀도가 0인 펫을 매일 +5씩 돌볼 경우 100에 도달하는 데 최소 20일이며, 강제 출석/연속 접속 조건은 두지 않는다.

## 7. 제작 우선순위 및 완료 조건
| 우선 | 항목 |
| --- | --- |
| P0 | 기본 표정·대기·걷기·먹기·쓰다듬기 |
| P1 | 앉기·눕기·잠자기·놀이·슬픔·삐짐 |
| P2 | 친밀도별 특별 반응/애정 표현 |

기존 승인 에셋을 먼저 확인하고 부족한 신규 행동만 제작한다. 앞선 우선순위는 제작 순서이며, 최종 리뉴얼 범위는 별도 MVP 승인과 연결한다. [TEST_PLAN](TEST_PLAN.md)의 추가 검증 항목을 적용한다. 현재 문서 승인만으로 구현 또는 테스트 통과를 의미하지 않는다.
