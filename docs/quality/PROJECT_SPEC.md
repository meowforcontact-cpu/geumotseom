# 그못섬 리뉴얼 기준서 (검토 초안)

이 문서는 리뉴얼 준비용이다. 별도 승인 기록이 있는 부분만 APPROVED로 간주한다. 그 외 새 기능의 승인 또는 기존 기능의 삭제를 의미하지 않는다. 현재 구현·배포의 출처는 [README](../../README.md)와 실제 코드다.

## 목표
디스코드 커뮤니티 활동을 펫 돌보기와 방 꾸미기로 이어 주고, 첫 행동과 재방문을 쉽게 만든다.

## MVP 후보 (DRAFT — 승인 필요)
| ID | 화면·기능 | 유지 검토/수용 조건 |
| --- | --- | --- |
| AUTH-01 | 계정 로그인·저장 | 사용자별 접근 제한, 충돌·재로그인 복원 |
| ROOM-01 | 기본 방·꾸미기 | 기존 원본 보존, 저장/복원, 배치 경계와 깊이 |
| PET-01 | 기본 펫 선택·돌보기 | 무료 선택 중복 방지, 기존 펫 데이터 보존; 돌보기·친밀도 세부 기획은 아래 승인 명세 참조 |
| SHOP-01 | 상점·보유함 | 체험 재화 구분, 중복 구매·미보유 적용 방지 |
| DAILY-01 | 출석·일일 미션 | 한국 날짜, 중복 보상 방지, 성공한 활동만 인정 |
| NAV-01 | 화면 전환 및 메뉴 | 현재 확정 규격·기존 접근 동선 검증 |

실제 운영 봇 재화 연동, 결제, 친구 방문, 추가 공간, 실시간 교류, AI 개인화는 별도 기획 및 검증 대상으로 둔다. 이 목록은 기존 기능을 폐기하지 않으며 구현 우선순위/범위를 확정하지 않는다.

## 승인된 세부 기획 (APPROVED — 구현 미검증)
- PET-01 상세: [펫 돌보기·친밀도 명세 v0.3](PET_CARE_SPEC.md) — 2026-11-17 사용자 승인(PET-001). 이 승인 범위는 네 가지 상태, 상호작용, 표정·행동 스프라이트, 감소 상한, 돌보기 제한이다. 전체 MVP/UI/UX/경제 기획 승인 또는 현행 코드 변경을 뜻하지 않는다.

- LIFE-01~07: [캐릭터 생활·꾸미기 추가 기획 v0.1](CHARACTER_LIFE_SPEC.md) — 이족보행, 대기/방치 모션, 성격별 대사, 의상, 가구 이용 미리보기, 시즌 가구, 구매 연출 및 스냅샷 공유 (LIFE-001). 구체적 구현 범위/일정은 상세 검토를 따른다.

## 리뉴얼 확정 절차
기존 화면·기능을 유지/개선/삭제/보류로 분류하고, 각 기능의 현행 코드·데이터·의존성을 조사한다. 사용자 승인을 받은 목록만/수용 조건에 따라 적용한다. 원본·데이터 마이그레이션·경제 변경은 별도 승인한다.
