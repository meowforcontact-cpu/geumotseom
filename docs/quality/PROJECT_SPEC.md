# 그못섬 리뉴얼 기준서 (검토 초안)

이 문서는 리뉴얼 준비용이다. 새 기능의 승인 또는 기존 기능의 삭제를 의미하지 않는다. 현재 구현·배포의 출처는 [README](../../README.md)와 실제 코드다.

## 목표
디스코드 커뮤니티 활동을 펫 돌보기와 방 꾸미기로 이어 주고, 첫 행동과 재방문을 쉽게 만든다.

## MVP 후보 (DRAFT — 승인 필요)
| ID | 화면·기능 | 유지 검토/수용 조건 |
| --- | --- | --- |
| AUTH-01 | 계정 로그인·저장 | 사용자별 접근 제한, 충돌·재로그인 복원 |
| ROOM-01 | 기본 방·꾸미기 | 기존 원본 보존, 저장/복원, 배치 경계와 깊이 |
| PET-01 | 기본 펫 선택·돌보기 | 무료 선택 중복 방지, 기존 펫 데이터 보존 |
| SHOP-01 | 상점·보유함 | 체험 재화 구분, 중복 구매·미보유 적용 방지 |
| DAILY-01 | 출석·일일 미션 | 한국 날짜, 중복 보상 방지, 성공한 활동만 인정 |
| NAV-01 | 화면 전환 및 메뉴 | 현재 확정 규격·기존 접근 동선 검증 |

실제 운영 봇 재화 연동, 결제, 친구 방문, 추가 공간, 실시간 교류, AI 개인화는 별도 기획 및 검증 대상으로 둔다. 이 목록은 기존 기능을 폐기하지 않으며 구현 우선순위/범위를 확정하지 않는다.

## 리뉴얼 확정 절차
기존 화면·기능을 유지/개선/삭제/보류로 분류하고, 각 기능의 현행 코드·데이터·의존성을 조사한다. 사용자 승인을 받은 목록만/수용 조건에 따라 적용한다. 원본·데이터 마이그레이션·경제 변경은 별도 승인한다.
