# Discord 연결 배포 안내

현재 상태: **서버 코드와 테스트 준비 완료 / 실계정 로그인 배포 전**. 로그인·닉네임 표시·계정별 체험 기록 저장까지만 다룹니다. 운영 잔액/상점 거래/역할에는 접근하지 않습니다.

## 호스팅 선택

추천은 **웹: Cloudflare Workers + Static Assets / 계정 저장: 별도 D1 / Discord 봇: 기존 DisHost 유지**입니다. 현재 봇의 작은 서버에 웹·AI 서버까지 얹지 않고, 웹이 재배포되어도 봇이 계속 실행되는 구성입니다.

무료 범위 확인(2026-11-04 공식 문서): 정적 파일 요청은 무료·무제한, Worker 실행은 Free 플랜 계정 전체 일 100,000회 제한입니다. D1 Free는 읽은 행 일 500만, 쓴 행 일 10만, 저장 총 5GB입니다. 기존 Worker가 있으면 무료 사용량을 합산해서 봐야 합니다. 한도를 넘으면 요청이 실패할 수 있으므로 무료가 무제한 서버를 의미하지는 않습니다.

| 후보 | 적합한 용도 | 이번 선택 |
|---|---|---|
| Cloudflare Workers + Static Assets + D1 | 화면 + Discord 로그인 + 계정 저장 | 정식 연동 후보. 무료로 시작하고 실제 사용량 확인 |
| Sites의 정적 배포 | 빠른 시연 주소와 버전 관리 | 이번 체험판 배포. 계정 API는 별도 연결 전 |
| GitHub Pages | 정적 화면만 배포 | 서버 OAuth·계정 저장은 별도 서버 필요. GitHub Free에서 Pages는 공개 저장소 대상이므로 비공개 운영 저장소를 공개하지 않음 |

## 설정할 항목

1. 기존 운영 대시보드와 다른 이름의 Worker `pika-pet-playtest`를 사용합니다. `integration/wrangler.example.jsonc`를 비공개 `wrangler.jsonc`로 복사합니다. 기존 대시보드의 DB/KV를 재사용하지 않습니다.
2. 새 체험용 D1을 생성하고 `PET_DB`로 연결합니다. **새 빈 DB에만** `schema.sql`을 적용합니다. 이 파일을 봇의 경제 DB나 후원 장부 DB에 적용하지 않습니다.
3. Worker에 `DISCORD_CLIENT_ID`와 실제 HTTPS 주소 `PUBLIC_ORIGIN`을 설정합니다. `PUBLIC_ORIGIN`은 끝 슬래시 없는 원점입니다. 현재 피카 앱 ID는 `1554992710723567757`이며, 별도 테스트 앱을 선택한다면 해당 ID로 바꿉니다.
4. `DISCORD_CLIENT_SECRET`은 Cloudflare의 **Secret**으로만 등록합니다. Bot Token은 사용하지 않습니다. 기존 Secret을 재설정/회전하지 말고, 권한 있는 기존 보관본을 사용하거나 소유자가 직접 입력합니다. Git·공개 파일·URL·채팅에 적지 않습니다.
5. Discord Developer Portal → 해당 앱 → OAuth2 → Redirects에 **`PUBLIC_ORIGIN/auth/discord/callback`**을 추가합니다. 예시 문자열 그대로 등록하지 말고 확정된 실제 주소를 사용합니다. 기존 Redirect를 지우지 않습니다. 일반 웹 로그인은 Activity의 URL Mapping과 별개입니다.
6. 프로젝트 루트에서 `npm run build`, `node integration/build-worker.mjs`, `npm test` 후 Worker/정적 파일을 함께 배포합니다.
7. 본인 로그인 → 닉네임 → 계정 저장 → 로그아웃 → 다른 기기 로그인 → 불러오기까지 확인합니다. 다른 사용자 계정에서는 첫 사용으로 보여야 합니다. 이 검증 전에는 “Discord 연결 완료”로 안내하지 않습니다.

## 연결 방식과 한계

- `/auth/discord`: 5분 유효한 일회용 state 발급 후 Discord로 이동. 조회 권한은 `identify` 하나.
- `/auth/discord/callback`: state·브라우저 쿠키 확인 후 코드 교환, 본인 프로필 확인, Discord 토큰 폐기 요청, 별도 웹 세션 발급.
- `/api/account/me`: 로그인한 본인의 표시 이름·CSRF 값만 반환.
- `/api/account/pet`: 본인 체험 진행 조회/저장. 저장 버전이 다르면 409로 덮어쓰기 거부.
- `/api/account/logout`: 현재 웹 세션 삭제.
- 연결 Secret·DB가 없으면 503, 로그인하지 않으면 401로 차단합니다. 인증 실패를 가짜 로그인 성공으로 바꾸지 않습니다.
- 이 계정 저장은 **체험용 진행의 기기 간 이동**입니다. 브라우저에서 편집 가능한 체험 재화를 운영 재화로 가져오면 안 됩니다. 실제 상점은 봇의 검증된 거래·중복 방지·잔액 차감 경로를 별도로 연결해야 합니다.

현재 SDK를 쓰는 기존 Discord Activity 화면과 이번 웹 체험판은 서로 다른 구현입니다. 이번 준비는 일반 웹 로그인이며, Activity 내부 OAuth와 실제 운영 구매는 각각 추가 검증이 필요합니다.

## 취소/복구

연동 배포가 실패하면 체험판 정적 버전으로 되돌립니다. 운영 봇은 변경하지 않았으므로 이전/재시작이 필요하지 않습니다. 새 Secret·새 DB만 사용하고 기존 운영 바인딩을 건드리지 않으면 체험판 실패가 운영 장부에 영향을 주지 않습니다. 공개 범위는 코드 배포와 별도로 관리합니다.
