# 그못섬 · 내 방

## 현재 기준 — 2026-11-05 원본 화면 복구

사용자가 제공한 `피카 다마고치.html`을 `src/pet.html`에 그대로 복구했다. 원본 파일의 본체, 캐릭터, 방, 가구 그림, 글꼴, 상점, 도감, 설정과 가로·세로 화면을 사용한다. 설정의 **테마 바꾸기**에서 블루와 핑크를 전환하고 새로고침 후에도 유지한다.

기존 브랜드 이름 그못섬은 빌드 시 제목에만 적용한다. `portal.js`, `tutorial.js`, `portal.css`의 변경 화면은 보관하며 현재 빌드에 포함하지 않는다. 이전 README의 개편 UI 설명은 이 원본 복구 기준으로 대체한다.

## 실행

Node 22 이상. `npm run build`, `npm test`, `npm start` 후 http://127.0.0.1:4207 접속.

단독 실행 파일: `outputs/그못섬-오프라인-체험판.html`. 그림과 실행 코드는 포함하며 원본 웹 글꼴을 불러오지 못하면 시스템 글꼴을 사용한다.

## 저장과 연동

`src/original-runtime.js`는 원래 메뉴 형식 안에서 저장·연결 기능을 제공한다. 기존 `pika.pet.playtest.v1` 저장 키와 진행 파일 형식을 유지한다. 설정 → 저장·연결에서 진행 파일 내보내기, 불러오기, 이름 변경을 할 수 있다. 구매한 물건은 보유 목록에 담기며 직접 적용한다. 잔액과 활동 데이터는 체험용이다.

Discord 로그인·계정 저장은 `integration/worker.mjs` 준비 코드가 있다. 실제 OAuth 설정과 DB가 연결되기 전까지 연결 준비 중으로 표시한다. 운영 피카봇·실제 재화 API는 호출하지 않는다. AI와 서버 활동량 연동은 아직 구현되지 않았다.

GitHub: https://github.com/meowforcontact-cpu/geumotseom

## 일일미션 1차 구현

활동 → 일일미션에서 출석·밥 주기·놀이 세 가지 달성 기록을 확인한다. 기존 원본 메뉴와 테마를 유지한다. 실제 성공한 돌보기만 기록하며 배부른 상태의 사료 주기, 알 상태 또는 배고픈 상태의 놀이 실패는 달성으로 세지 않는다. 한국시간 자정에 갱신하고 새로고침·진행 파일 복원 시 보존한다. 기존 저장도 읽을 수 있다.

현재는 브라우저 체험 기록이며 미션 보상 금액·XP를 추가 지급하지 않는다. 보상량, 서버 검증, Discord 활동 기반 미션은 후속 결정과 연동이 필요하다. GPU 실행은 오류가 있었다는 사용자 설명에 따라 새 모델 실험을 우선순위에서 내렸으며, 생성 성공 증빙은 아직 확보하지 않았다.

## 검증

`npm test`로 저장·구매·OAuth·원본 설정 호환성을 검사한다. 보관한 이전 UI의 회귀 검사도 포함한다. 브라우저에서 원래 설정 메뉴, 블루→핑크 전환, 새로고침 후 핑크와 잔액 유지 확인.
