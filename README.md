# 그못섬
디스코드 활동 보상을 펫 육성과 방 꾸미기로 확장하는 커뮤니티 웹 서비스입니다.

- 공개 베타: https://geumotseom-beta.meowforcontact.workers.dev/
- GitHub: https://github.com/meowforcontact-cpu/geumotseom

## 해결할 문제와 이용자
신규 회원은 복잡한 명령어와 기존 친목 관계 때문에 첫 참여를 어려워합니다. 서버 운영자는 신규 회원의 적응과 기존 회원의 이탈·참여 저하를 고민합니다. 출석과 일일미션으로 첫 행동을 안내하고, 펫 성장과 꾸미기로 다시 방문할 이유를 제공하는 것이 목표입니다. 효과 향상은 아직 측정하지 않았습니다.

## 현재 구현과 배포 상태 (2026-11-06)
| 기능 | 상태 |
| --- | --- |
| 펫 돌보기, 출석, 일일미션, 상점, 보유함, 방 꾸미기 | 체험판 구현 |
| 블루·핑크 테마, 가로·세로 기기 화면 | 구현 |
| Discord OAuth 로그인 | 공개 베타에서 실제 재로그인 확인 |
| 계정별 진행 저장·복원 | Cloudflare Worker·D1 연결, 동일 계정 재로그인·새로고침 복원 확인 |
| 실제 운영 봇 XP·잔액 연동 | 미구현. 현재 잔액은 체험용 |
| 광장 실시간 교류, 친구 방문, 쪽지, 게시판 | 후속 개발. 준비 화면을 완료 기능으로 안내하지 않음 |
| 유료 꾸미기 아이템 | 계획 단계 |
| 서비스 내부 AI 추천·생성 기능 | 미구현 |

**이전 README의 “Discord 로그인·DB는 준비 코드” 설명은 배포 전 기록입니다.** 공개 베타에서는 OAuth 콜백 후 계정 진행과 저장됨 표시, 로그아웃·재로그인 후 기존 잔액 복원을 확인했습니다. 다른 회원·다른 기기 실사용 검증은 아직 끝내지 않았습니다. 계정 간 접근 차단과 저장 충돌 처리는 자동 테스트 범위입니다. 정적·오프라인 체험판은 서버 로그인 없는 별도 실행 방식입니다.

## 핵심 이용 흐름
현재 체험판은 출석·돌보기 기록, 체험 재화로 아이템 구매, 보유함에서 방 적용까지 제공합니다. 일일미션은 성공한 출석·밥 주기·놀이만 기록하며 한국시간 자정에 갱신합니다. 미션 완료 자체의 추가 XP 지급은 아직 없습니다.
최종 목표인 **Discord 활동 → 실제 XP 보상 → 아이템 구매·꾸미기**에서 실제 활동 보상 연결은 후속 작업입니다. 체험 잔액을 운영 서버의 실제 재화처럼 표시하지 않습니다.

## AI 활용 범위와 후속 계획
AI와 협업해 화면 흐름과 구현을 검토하고, 픽셀 표현·색상·구도 조건을 정리한 이미지 프롬프트를 작성했습니다. 틸론 SDXL 계열 이미지 생성 실습은 콘텐츠 제작 과정이며, 서비스 안에서 실시간 AI가 동작하는 기능과 구분합니다. 생성 성공·서비스 적용은 결과와 실행 증빙을 확인한 범위에서만 설명합니다.
다음 단계는 서버 활동을 입력받는 일일미션 추천입니다. 활동 데이터 입력·AI 모델 호출·결과 표시가 연결된 후 구현 완료로 표시합니다. 현재는 계획이며 규칙 기반 추천을 AI라고 부르지 않습니다.

## 운영 근거와 검증 계획
직접 운영하는 커뮤니티에서 2026-11-06 기준 2,479명을 확인했습니다. Statbot의 2026-10-23~11-05 UTC 일별 합계는 메시지 68,164건, 음성 이용 6,347.71 인시입니다. 여러 이용자의 음성 시간을 합친 값이며 그못섬 도입 효과가 아닙니다. 기존 XP 상점의 한정 칭호·닉네임 그라데이션·이모지 소비 경험을 기획 근거로 삼았습니다.
후속 측정 지표는 신규 회원의 첫 미션 완료율과 7일 재방문율입니다. 유료 매출·유지율 개선은 아직 검증하지 않았습니다.

## 최신 에셋 제작 기준 (2026-11-12)

- [픽셀 에셋 제작 기준서](docs/pixel-asset-style-guide.md): **소재·부품별 기본색+명암 2색, 필요시 최대 3색, 공통 외곽선 별도** (에셋 전체 색 수 제한 아님); 1픽셀 짙은 갈색 윤곽, 도트 선명도 및 잘림 방지 규칙.
- [프로젝트 작업 메모리](MEMORY.md): 기존 8방향 고양이·빈방·기본 배치의 보존 지시 및 검수 순서.
- [카메라·가구 배치 기준서](docs/room-camera-standard.md): 4:3 미들앵글 2.5D 좌표계.
- 이 문서 반영은 규칙 갱신이며, 이전 PNG 전체와 렌더러의 색상 기준 준수/배포를 의미하지 않습니다.

## 실행과 저장
Node.js 22 이상에서 아래 명령을 실행합니다.
```sh
npm run build
npm test
npm start
```
로컬 주소: http://127.0.0.1:4207
단독 체험: `outputs/그못섬-오프라인-체험판.html`
공개 서버 진입점: `integration/worker.mjs`. 공개 배포에는 별도 Discord OAuth 설정과 D1, 서버 환경변수가 필요합니다. 비밀값은 저장소에 포함하지 않습니다.
기존 `pika.pet.playtest.v1` 저장 키와 진행 파일 호환성을 유지합니다. 설정의 저장·연결에서 파일 내보내기와 불러오기를 제공합니다.

## 보안과 확인 범위
Discord 권한은 기본 프로필 identify 범위입니다. 운영 봇의 실제 잔액·역할 DB를 호출하지 않습니다. OAuth·저장·구매·날짜 갱신 회귀 테스트를 포함합니다. 자동 테스트와 실제 브라우저 검증은 구분하며, 공개 베타 동일 계정 복원 확인을 모든 사용자·모든 기기 검증으로 확대해 설명하지 않습니다.
